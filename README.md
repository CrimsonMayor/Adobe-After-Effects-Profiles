## Usage

### For Applying Animation Presets:
1. Launch Adobe After Effects and open your project.
2. Open the **Effects & Presets** panel (**Window** → **Effects & Presets**).
3. Load the provided animation presets via the panel menu → **Browse Animation Presets**.
4. Navigate to the extracted preset files (`.ffx` or `.aep`).
5. Drag and drop the preset onto your layer or select the layer and double-click the preset to apply.

### For Loading Templates:
1. Open the **Project** panel and use **File** → **Import** → **File**.
2. Select the template file (`.aep` or `.aet`) from the collection.
3. Choose **Import Kind: Composition** to import the template as a composition.
4. The template will appear in your Project panel.
5. Drag the composition to your timeline and customize as needed.

### For Running Scripts:
1. Navigate to **File** → **Scripts** → **Run Script File**.
2. Locate the JavaScript (`.jsx` or `.jsxbin`) script from the collection.
3. Select the script and click **Open** to execute it.
4. Follow any on-screen prompts or dialogs.
5. The script will automate the designated task on your active project.

### For Color Grading:
1. Load the provided LUTs via the **Lumetri Color** effect or the **Apply Color LUT** effect.
2. In the **Effects & Presets** panel, search for "Apply Color LUT".
3. Drag the effect onto your adjustment layer or footage.
4. In the Effect Controls panel, click **Choose LUT** and navigate to the `.cube` file from the collection.
5. Adjust the intensity using the controls provided.

### For Rendering and Export:
1. Open the **Render Queue** (**Composition** → **Add to Render Queue**).
2. Load the provided render settings via the **Render Settings** dropdown → **Load Settings**.
3. Select the appropriate render profile for your output format.
4. Configure the output module settings (format, codec, resolution) using the provided presets.
5. Click **Render** to start the rendering process.

### For Expressions:
1. Select the property you want to animate (e.g., Position, Scale, Opacity).
2. Hold **Alt** (Windows) or **Option** (Mac) and click the stopwatch icon to add an expression.
3. In the expression field, paste or type the expression from the provided library.
4. Adjust the expression parameters as needed.
5. Preview the animation to ensure the expression works as expected.
